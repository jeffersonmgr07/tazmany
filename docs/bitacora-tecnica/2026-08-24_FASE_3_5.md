# Bitácora técnica — 2026-08-24 — Fase 3.5

## Objetivo

Permitir que GitHub Pages sea la interfaz visible de Tazmany y que se comunique con el backend de Apps Script mediante un relay sin exponer Sheets ni secretos en el navegador.

## Versión

`0.3.5`

## Archivos principales

- Nuevos: `FrontendApiGateway.gs`, `FrontendBridgeSetup.gs`, Worker, configuración Wrangler, ADR, arquitectura, despliegue, pruebas y notas de capacitación.
- Modificados: `Main.gs`, `Config.gs`, `scripts.html`, generador de preview, validación, README, changelog y versión del paquete.

## Reglas

- Solamente `/exec/api` recibe operaciones del frontend remoto.
- No existe despacho dinámico por nombre de función; se usa una allowlist.
- El relay secret nunca se escribe en GitHub, HTML, logs ni Sheets.
- Los orígenes se comparan exactamente.
- Mercado Pago sigue sin código operativo.

## Pruebas

- Rechazo de origen no permitido.
- Reenvío de acción autorizada.
- Conservación del secreto únicamente en el relay.
- Bloqueo de funciones administrativas de setup.
- Regresión de autenticación, RBAC, tema y cálculos.

## Riesgos pendientes

- Probar OTP con correo real y Google Identity con origen GitHub autorizado.
- Ejecutar matriz multirol con cuentas controladas de desarrollo.
- Configurar límites adicionales en Cloudflare antes de producción.
