# Ficha técnica / bitácora — Fase 1

**Fecha:** 2026-08-24  
**Versión:** 0.1.2  
**Objetivo:** crear una base ejecutable con index, dashboard de cliente y dashboard de comercio.

## Archivos creados

- Backend: configuración, router, validación, seguridad, utilidades, repositorio, setup, seed y servicios de lectura.
- Frontend: shell público, componentes, dashboards, sistema visual y controladores.
- Operación: manifiesto Apps Script, clasp, GitHub Actions y scripts de verificación.
- Documentación: arquitectura, esquema, manual inicial, capacitación, ADR y changelog.

## Reglas implementadas

- IDs lógicos; las filas físicas no se publican.
- Dinero en céntimos enteros.
- Descuento calculado, no escrito manualmente en UI.
- Errores públicos encapsulados.
- Datos financieros demo claramente identificados.
- `setupTazmany()` y `seedDemoData()` ejecutables varias veces sin duplicar IDs.
- Hojas de eventos y finanzas preparadas para historial; no se habilitó borrado.

## Seguridad

- Sin tokens ni contraseñas en código.
- El navegador no recibe acceso a Sheets.
- Validación básica de identificadores.
- `LockService` disponible para las operaciones críticas de fases siguientes.
- `doPost` no procesa eventos en Fase 1.

- Composición de preview estático.
