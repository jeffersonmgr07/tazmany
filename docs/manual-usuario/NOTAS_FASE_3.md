# Notas de usuario — Fase 3

## Propietario del comercio

- Abre **Comercio** desde el menú de perfil.
- Si todavía no existe un negocio, completa el expediente y guárdalo como borrador.
- **Enviar a verificación** bloquea temporalmente la edición hasta que Tazmany responda.
- Una observación debe corregirse antes de volver a enviar.
- El contrato solo puede generarse cuando el comercio está aprobado.
- Para enviar campañas a revisión se necesita un contrato aceptado.

## Gestor de campañas

- Registra precios verificables, stock real, sedes, vigencias, incluidos y restricciones.
- **Guardar borrador** no publica la oferta.
- **Guardar y enviar** crea una versión para moderación.
- Una campaña publicada conserva su versión; los cambios materiales requieren revisión.

## Administrador Tazmany

- El panel **Administración** muestra expedientes y campañas pendientes.
- Aprobar u observar exige permisos backend.
- Toda observación debe incluir un motivo verificable.
- Las decisiones quedan en historial y auditoría.

GitHub Pages es una demostración visual. El guardado real funciona únicamente en la Web App de Apps Script.
