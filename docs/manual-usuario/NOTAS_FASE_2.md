# Manual de usuario — notas de Fase 2

## Cliente

1. Pulsa **Ingresar**.
2. Continúa con Google o escribe tu correo para recibir un código.
3. El código tiene seis dígitos y vence en diez minutos.
4. Completa nombres, documento, celular y ciudad.
5. Acepta términos y privacidad; marketing es opcional.
6. Desde **Seguridad y sesiones** puedes cerrar el acceso de otro dispositivo.

El celular todavía aparecerá pendiente de verificación. Esto no habilita compras porque Mercado Pago continúa desactivado.

## Comercio

El panel solo se abre si la cuenta tiene un registro activo en `MERCHANT_USERS` y el rol incluye `merchant.dashboard.read`. El cajero no obtiene permisos financieros por acceder a una URL.

## GitHub Pages

La URL de Pages sirve para revisar diseño, responsive y navegación demo. El ingreso real y la conexión con Sheets se prueban únicamente en la Web App de Apps Script.
