# Manual de usuario — notas acumulativas

## Comprador

1. En Inicio puede explorar ofertas y filtrar por categoría o texto.
2. Cada tarjeta muestra comercio, ubicación, precio regular, precio Tazmany, descuento y cashback.
3. Al abrir una oferta aparecen incluidos, restricciones y sedes.
4. La opción **Cliente** abre “Mi Tazmany”: cupones, compras, cashback y favoritos.
5. En esta versión no se realizan cobros. El botón de compra informa que Checkout se habilitará en Fase 4.
6. Los botones amarillos representan acciones principales; los bloques navy identifican confianza, protección y navegación.

## Propietario de comercio

1. La opción **Comercio** abre el dashboard de demostración.
2. El resumen muestra ventas, canjes, cupones por atender y próximo pago estimado.
3. “Campañas activas” compara vendidos, inventario e ingreso bruto.
4. “Escanear cupón” abre una explicación; el canje real se implementará en Fase 5.
5. El botón amarillo “Escanear cupón” es la acción operativa principal; no ejecuta canjes reales en esta fase.

## Administradores Tazmany

El shell existe, pero no contiene operaciones. No usarlo para aprobar comercios o campañas hasta disponer de RBAC y auditoría.
