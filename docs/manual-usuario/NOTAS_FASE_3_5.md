# Notas de usuario — Fase 3.5

- La dirección pública será GitHub Pages mientras se prepara el dominio oficial.
- El usuario no debe abrir la URL de Apps Script para navegar normalmente.
- El ingreso por OTP utiliza un correo real; los correos `@demo.tazmany.pe` no son buzones.
- Un usuario nuevo creado por Google u OTP empieza como cliente.
- Ser propietario de comercio o administrador requiere una asignación backend aprobada.
- Si el relay no está configurado, la página muestra datos demo y avisa que falta conexión.
- Ningún botón procesa pagos en esta versión.
