# Capacitación — Fase 3.5

## Cliente de prueba

1. Abrir la URL de GitHub Pages.
2. Solicitar OTP con un correo real controlado.
3. Verificar el código de seis dígitos.
4. Completar perfil y consentimientos.
5. Cerrar y restaurar sesión.

## Propietario de comercio

1. Ingresar con una cuenta de desarrollo a la que se asignó `MERCHANT_OWNER`.
2. Verificar que solo vea su comercio, sucursales, documentos y campañas.
3. Probar doble clic en guardar y confirmar que no se duplique el registro.

## Administrador Tazmany

1. Ingresar con una cuenta real vinculada a un rol administrativo de desarrollo.
2. Confirmar que un cliente no pueda abrir la moderación manipulando la URL.
3. Revisar auditoría después de aprobar u observar.

## Operación técnica

- No compartir el secreto del relay.
- No pegar tokens de sesión en capturas o chats.
- Ante un origen bloqueado, revisar la configuración exacta; no usar `*`.
- Mercado Pago permanece deshabilitado.
