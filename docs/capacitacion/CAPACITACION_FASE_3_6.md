# Capacitación — Ubicación, suscriptores y Club

1. Cambia la ciudad desde el encabezado o la banda sobre el catálogo.
2. Para sugerirla, pulsa el botón de ubicación y confirma la propuesta.
3. Un suscriptor gratuito no es un usuario registrado y no puede comprar hasta autenticarse.
4. En campañas, el precio público aplica a cualquier comprador; el precio Club se reserva a una membresía activa futura.
5. El estado `COMING_SOON` significa que no existe cobro ni membresía activa todavía.
